# Українські матеріали до прикладів

Цей каталог містить українські версії документації, пов'язаної з перевіркою
методу ієрархічного узагальнення процесної моделі. Українські тексти призначені
для читання та рецензування. Розрахунки виконувалися за англомовними назвами
операцій, оскільки текстова компонента `S_txt` залежить від мови й конкретних
формулювань.

Каталог містить три набори:

| Каталог | Призначення | Статус результатів |
|---|---|---|
| `article_control_18_nodes` | Українська реконструкція п'яти документів D1-D5, що пояснюють контрольний граф зі статті | Результати зафіксовано за дослідницькою версією методу, використаною для статті |
| `access_recovery_as_is` | Переклад поточного англомовного корпусу відновлення доступу | Реальний повторний прогін поточної детермінованої реалізації без LLM і без попереднього виправлення гіпотез аналітиком |
| `home_internet_as_is` | Переклад поточного англомовного корпусу підключення домашнього інтернету | Реальний повторний прогін поточної детермінованої реалізації без LLM і без попереднього виправлення гіпотез аналітиком |

Контрольний приклад і два AS-IS прогони не слід безпосередньо порівнювати за
кількістю атомарних вузлів. Перед контрольним розрахунком аналітик перевірив
кандидатні дії, умови й переходи та сформував узгоджений граф із 18 вузлів.
У двох додаткових прогонах усі підтримувані правилами гіпотези залишено в моделі,
тому `L0` містить відповідно 98 і 118 вузлів. Поточна реалізація також не
використовувала LLM, через що не усувала неявні дублікати та семантичні
неоднозначності.

Англомовні джерела додаткових прогонів розміщено в:

- `examples/access_recovery_source_docs`;
- `examples/home_internet_connection_docs`.

Машинозчитуваний контрольний граф і звіт його згортання розміщено в:

- `examples/access_recovery_process.md`;
- `examples/access_recovery_aggregation.md`.
