# Підключення домашнього інтернету — AS-IS приклад

Ця папка містить український переклад документів із
[`examples/home_internet_connection_docs`](../../examples/home_internet_connection_docs).
Переклад призначений для читання та змістової перевірки прикладу. Результати в
`experiment_results_ua.md` отримано поточною детермінованою реалізацією на
англомовних оригіналах, без LLM і без ручного виправлення виділених карток.

Через переклад назви дій і лексична подібність можуть змінитися, тому ці файли
не слід використовувати як буквальний вхід для відтворення наведених чисел.

## Склад набору

- `D1_policy_uk.md` — політика виконання замовлення;
- `D2_order_guide_uk.md` — наскрізний маршрут замовлення;
- `D3_serviceability_uk.md` — перевірка технічної можливості та доступу;
- `D4_customer_agreement_uk.md` — ідентифікація клієнта і договір;
- `D5_appointment_uk.md` — призначення візиту;
- `D6_field_installation_uk.md` — польовий монтаж;
- `D7_activation_uk.md` — активація і технічне тестування;
- `D8_acceptance_closure_uk.md` — приймання послуги, білінг і закриття;
- `experiment_results_ua.md` — зафіксовані результати прогону.
