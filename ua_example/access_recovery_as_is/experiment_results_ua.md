# Результати AS-IS прогону для відновлення доступу

Результат отримано на п'яти англомовних документах із
`examples/access_recovery_source_docs` поточною детермінованою реалізацією.
LLM не використовувалася. Гіпотези, сформовані за порядком дій у розділах, не
перевірялися й не виправлялися аналітиком до побудови ієрархії.
