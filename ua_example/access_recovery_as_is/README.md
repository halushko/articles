# Відновлення доступу AS-IS

Це український переклад англомовного корпусу
`examples/access_recovery_source_docs`. Оригінали написано як звичайну внутрішню
документацію без ідентифікаторів вузлів, повної таблиці переходів або наперед
заданих рівнів ієрархії.

Результати в `experiment_results_ua.md` отримано реальним прогоном поточної
детермінованої реалізації на англомовних оригіналах. LLM не використовувалася,
а низьковпевнені гіпотези послідовності не виправлялися аналітиком. Український
переклад призначений лише для читача; його не слід подавати на вхід поточному
англомовному адаптеру або використовувати для перерахунку `S_txt`.
