БЕЗ УПРАВЛЕНИЯ УСТРОЙСТВАМИ
Как это работает: Подтверждённые записи из SQLite доступны ученику через поиск и граф сущностей/связей. Новые гипотезы требуют проверки учителя. Контрольный режим «Только LLM» намеренно изолирован от этой памяти, чтобы можно было сравнивать качество без обучения.

В режиме «Спросить» запрос не покинет JARVIS до нажатия «Разрешить поиск». В «Автопоиске» сформулированный запрос отправляется внешним поисковикам SearXNG. Ответы из интернета не становятся подтверждёнными знаниями.

Реальные возможности

Изучить API и реально вызвать API — разные вещи. Без подключённого исполнителя сетевые действия запрещены.

Что ещё не умеет

Список действий в памяти не является доступом к инструментам. Джарвис пока не может выполнять код, делать произвольные HTTP-запросы или управлять домом. Исключение — ограниченный поиск и чтение публичных страниц через SearXNG.

У Qwen остаются общие знания. Наше обучение дополняет их без изменения весов модели.
