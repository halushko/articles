# Supplier Integration Runbook

- **Runbook owner:** Integration Engineer
- **Primary system:** Integration Console
- **Entry condition:** GRC Hub contains a valid compliance approval

## Configure the integration

1. Configure integration workspace in the Integration Console.
2. Configure integration credentials in the Integration Console.
3. Configure integration connectivity in the Integration Console.

The successful connectivity test is the formal hand-over to Finance
Operations. Secrets and detailed diagnostic logs are not included in the
financial hand-over.
