# Premises Serviceability and Building Access Procedure

- **Procedure reference:** HIF-NET-004
- **Procedure owner:** Access Network Planning
- **Used in:** Network Inventory System
- **Entry condition:** A residential order contains a complete installation address

## Validate the address

Compare the submitted address with the national address register and the
provider's premises inventory. Correct formatting differences only when the
building, entrance and unit can be identified without ambiguity.

Request clarification from Order Management when the unit number is missing or
when two premises records could represent the same address. Preserve the
customer's original wording in the order history.

## Check network reach and capacity

Locate the serving distribution point in the Network Inventory System. Review
the supported access technology, spare port capacity, distance limits and any
open network incident affecting the route to the premises.

When capacity is available, reserve a port against the order for the configured
reservation period. When capacity is exhausted, create a capacity request and
record its planning owner instead of making a speculative reservation.

## Confirm permission to enter and install

Review building notes for an existing wayleave, equipment-room access rules and
approved cable routes. Contact the building manager when shared property must be
entered or altered. For a rented unit, record whether the proposed work requires
the landlord's consent.

Attach written permission when it is required. A verbal assurance from the
customer is not sufficient for drilling, façade work or changes in a shared
communications room.

## Decide the serviceability outcome

Treat the premises as serviceable when a supported network route, usable
capacity and all required access permissions are available.

Treat the premises as blocked when capacity, a permitted cable route or a
required building approval is unavailable.

## Handle a blocked serviceability result

Record the exact blocker, responsible team and earliest review date. Release any
temporary port reservation that cannot be used. Tell Order Management whether a
network build quotation, additional landlord evidence or a later capacity check
could change the result.

## Return the serviceability result

Update the order with the confirmed technology, maximum sellable profile,
reservation identifier and installation constraints. Return a serviceable or
blocked status together with the evidence used for that decision.
