# Residential Field Installation Runbook

- **Runbook reference:** HIF-FLD-011
- **Runbook owner:** Field Operations
- **Primary tools:** Field Service Application, optical power meter, cable tester
- **Entry condition:** A technician has a dispatched installation job

## Accept and prepare the job

The technician reviews the address, contact details, access notes, reserved
network port and required equipment in the Field Service Application. Confirm
that the gateway and installation materials match the work order before travel.

## Confirm the work with the customer

On arrival, verify the premises and the adult contact. Review the planned cable
route and gateway position before drilling or attaching equipment. Explain any
visible work and obtain the required on-site consent.

## Install the access connection

Inspect the existing drop cable and outlet when present. Install or replace the
approved drop, termination point and internal cable needed for the ordered
service. Label the provider equipment with the order or circuit reference.

Do not use an unapproved shared cable route or conceal damage discovered during
the work. Record a premises or network blocker when safe installation cannot
continue.

## Install the home gateway

Connect the assigned home gateway at the agreed location. Record its serial
number and network identifier in the Field Service Application. Confirm power,
link indication and the customer's preferred local connection method.

## Decide the field-work outcome

Treat the field job as installed when the physical link is complete, the
assigned equipment is connected and no premises blocker remains.

Treat the field job as failed when access is refused, the reserved network path
cannot be used or the physical work cannot be completed safely.

## Handle a failed installation

Make the site safe and retain reusable provider equipment. Photograph or
otherwise record the blocker when permitted. Create the appropriate follow-up
task and give scheduling a clear prerequisite for the next visit.

## Return the installation record

Upload the cable route, outlet, equipment identifiers, measurements, consent
record and completion status. Return the job to Order Management as installed
or failed; do not mark activation complete from the field application.
